# VideoSorter · 视频分值统计工具

把一批视频素材拖进来，自动按「多档累进」规则算分，一键生成可直接复制的每日工作日报文案，并可把统计写入 / 导出到 Excel 每日统计表。

提供两种形态，计分逻辑完全一致：

| 版本 | 形态 | 特点 |
|---|---|---|
| **桌面版** | Windows exe（PySide6） | 双击即用；可直接选 Excel 并一键「同步至表格」写入；日期按视频**创建时间** |
| **网页版** | 单文件 HTML（离线可用） | 浏览器 / 手机打开，跨平台免安装；导出 Excel / CSV 下载；日期按**修改时间** |

## ✨ 功能特性

- 拖拽 / 多选 / 选文件夹，批量导入视频
- 多档累进计分，自动按时长分档
- 自动按素材日期归类（取多数那一天）
- 一键复制日报文案（含各档镜头明细）
- Excel 统计：桌面版自动追加行；网页版导出下载
- 类目输入历史（桌面版随程序目录保存；网页版存浏览器本地）

## 📊 计分规则（多档累进）

| 视频时长 | 分值 |
|---|---|
| 1 ~ 12 秒 | 1 分 |
| 13 ~ 17 秒 | 2 分 |
| 18 ~ 22 秒 | 3 分 |
| 23 ~ 27 秒 | 4 分 |
| 28 秒及以上 | 每多 5 秒 +1 分（28~32 秒 = 5 分，33~37 秒 = 6 分 …） |

每条视频按自身时长落入对应档位计分，所有视频得分相加即总分数。

## 📝 日报文案格式

```text
8月21日
一、今日工作
1、拍摄神龙女鞋视频175条，其中1~12秒镜头150条150分，13~17秒镜头3条6分，18~22秒镜头22条66分
2、合计175条，222分
二、明日规划
1、高优先级：***
2、一般优先级：
三、思考：
```

- 类目未填时显示 `***`；日期自动取素材的多数日期
- 「明日规划 / 思考」留空，复制后自行补充

## 🖥 桌面版（Windows）

源码：`desktop/app.py`

```bash
pip install -r requirements.txt
python desktop/app.py
```

打包为单文件 exe：

```bash
pyinstaller --onefile --windowed --icon desktop/icon.ico ^
  --hidden-import av --hidden-import openpyxl desktop/app.py
```

使用流程：双击 exe → 点「选择统计表」选一次 Excel → 拖入视频算分 → 复制文案 → 点「同步至表格」。

**Excel 格式要求**：需含以月份命名的工作表（如 `8月`），表头 6 列：
`日期 | 类目 | 类型 | 个数 | 分数 | 备注`。程序会在该表最后一个有数据的行之后追加新数据。

## 🌐 网页版（离线单文件）

源码：`web/index.html`，已内联 SheetJS，**无需联网**。

用浏览器打开即可使用；手机浏览器可从相册选择视频。导出 Excel / CSV 均在本机浏览器内生成。

## ⚠️ 注意事项

- 桌面版由 PyInstaller 打包，个别杀毒软件可能误报，加入白名单即可
- 网页版受浏览器安全限制，不能直接改写本机 Excel 文件，故采用「导出下载再合并」的方式
- 日期依据：桌面版=文件创建时间，网页版=文件最后修改时间，可在表格中手动修正
